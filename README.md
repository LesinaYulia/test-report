# Своя Дача — сайт-визитка

Одностраничный лендинг для аренды дачи с баней под Екатеринбургом.
Чистый HTML/CSS/JS без сборки — открывается и хостится как есть.

## Структура

```
index.html            главная страница
privacy.html           политика обработки персональных данных (ссылка из формы/подвала)
assets/css/styles.css  все стили (цвета — переменные в самом верху файла)
assets/js/config.js    контакты сайта: телефон, WhatsApp, Telegram, Instagram, e-mail, карта
assets/js/main.js      меню, липкая шапка, появление блоков, галерея-лайтбокс, форма заявки
assets/img/*.svg       иллюстрации-заглушки (см. ниже)
robots.txt, sitemap.xml базовая SEO-разметка
```

## Что нужно поменять перед публикацией

1. **Контакты** — откройте `assets/js/config.js` и впишите реальные телефон,
   WhatsApp/Telegram, e-mail и ссылку на карту. Это единственное место,
   где их нужно менять — по сайту они подставляются автоматически.
2. **Фотографии.** Instagram недоступен из этой рабочей среды, поэтому
   вместо реальных фото сейчас — стилизованные SVG-иллюстрации домика,
   бани, чана и беседки (`assets/img/*.svg`). Замените файлы
   `hero.svg`, `about.svg`, `gallery-1.svg` … `gallery-6.svg`, `map.svg`
   и `og-cover.svg` на реальные фотографии (можно оставить те же имена
   файлов с расширением `.jpg`/`.webp` — тогда достаточно поправить
   ссылки в `index.html` на новое расширение).
3. **og-cover** сейчас тоже SVG — для корректного превью в соцсетях и
   мессенджерах замените на `.jpg`/`.png` 1200×630 и обновите
   `<meta property="og:image">` в `index.html`.
4. **Домен.** В `index.html` уже проставлен `https://svoyadacha-ekb.ru/`
   (canonical, og:url, JSON-LD, sitemap.xml) — замените на свой домен
   после покупки/подключения.
5. **Юрлицо/ИП в политике.** В `privacy.html` — общий шаблон согласия на
   обработку персональных данных, при необходимости дополните реквизитами.

## Форма заявки

Форма бронирования (`#booking`) работает без бэкенда: если в
`config.js` не указан `formEndpoint`, при отправке открывается WhatsApp
с готовым текстом заявки. Если подключите любой сервис приёма форм
(Formspree, Getform, собственный обработчик) — впишите его URL в
`formEndpoint`, и заявки будут уходить туда по HTTP, а WhatsApp останется
резервным вариантом при сбое.

## Локальный просмотр

Любой статический сервер подойдёт, например:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/
```

## Публикация

Сайт статический — подходит любой хостинг: обычный shared-хостинг по
FTP, Netlify/Vercel (папка как есть, без сборки) или GitHub Pages.

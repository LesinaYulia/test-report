# Своя Дача — сайт бренда

Лендинг загородного дома «Своя Дача» под Екатеринбургом. Чистый HTML/CSS/JS
без сборки и фреймворков — открывается и хостится как есть.

Идея бренда: «Всё уже есть. Осталось приехать.» Дизайн намеренно уходит от
типового сайта посуточной аренды — тёплый минимализм, без градиентов,
без «зелёных кнопок на каждом шагу», с акцентом на спокойствие и детали.

## Структура

```
index.html              главная страница (все 12 блоков по брифу)
privacy.html            политика конфиденциальности
booking-terms.html      условия бронирования
404.html                страница «не найдено» (со слотом под персонажа «Свой»)
assets/css/styles.css   вся дизайн-система: токены, типографика, секции
assets/js/config.js     контакты сайта (телефон, WhatsApp, Telegram, e-mail)
assets/js/main.js       меню, липкая шапка, параллакс, reveal, форма, sticky-CTA
assets/img/favicon.svg  минималистичная марка бренда
assets/img/og-cover.svg превью для соцсетей (см. «Что нужно заменить»)
robots.txt, sitemap.xml базовая SEO-разметка
```

## Дизайн-система

Все значения — переменные в самом верху `assets/css/styles.css`:

- **Цвет**: молочный `#F5F1E8`, белый `#FCFBF7`, глубокий зелёный `#3F5142`
  (акцент/CTA), шалфейный `#A8B39A`, тёплый бежевый `#D8CBB8`, древесный
  `#8A7058`, графит `#353735`. Зелёный использован точечно — как акцент и
  для кнопок, а не как заливка.
- **Шрифты**: заголовки — Cormorant Garamond, текст и кнопки — Manrope.
  Подключены через Google Fonts.
- **Без градиентов**, минимум декоративных элементов, крупные фото-блоки.
- Плейсхолдеры фотографий сделаны через общий SVG-фильтр «зерно»
  (`#grain` в `index.html`) поверх плоского цвета из палитры — без единого
  внешнего изображения-заглушки и без градиентов.

## Что здесь — заглушки, а не реальные данные

Бриф прямо просил не выдумывать характеристики. Всё содержательное (метраж,
вместимость, состав дома, что включено, список деталей в разделе «Забота
в деталях») взято из ТЗ дословно. А вот там, где данных не было, сделаны
понятные заглушки — их нужно заменить перед публикацией:

1. **Фотографии.** Instagram-профиль проекта недоступен из этой рабочей
   среды, поэтому вместо реальных фото на сайте — крупные плейсхолдеры:
   плоский цвет из палитры + лёгкое зерно + подпись, что именно должно
   быть на фото («Кухня-гостиная», «Терраса», «Баня» и т.д.). Чтобы
   вставить настоящий кадр — замените `<div class="photo ...">` внутри
   нужного `.photo-frame` на `<img src="..." alt="...">` с теми же классами
   `ratio-*` на обёртке. Подпись (`.photo-frame__label`) можно убрать или
   оставить как источник `alt`.
2. **og-cover.** Сейчас превью для соцсетей — SVG-заглушка с
   типографикой бренда. Для корректного отображения в мессенджерах
   замените на `.jpg`/`.png` 1200×630 и поправьте `og:image` в
   `index.html`.
3. **Контакты.** `assets/js/config.js` — телефон, WhatsApp, Telegram,
   e-mail сейчас в формате очевидных плейсхолдеров (`+7 (900) 000-00-00`
   и т.п.). Впишите реальные — подставятся сами по всему сайту.
4. **Отзывы.** Реальных отзывов гостей не было в ТЗ — на сайте три
   карточки с пунктирной рамкой и текстом «[Здесь появится отзыв гостя]».
   Замените на настоящие цитаты, когда они появятся; выдумывать отзывы
   намеренно не стали.
5. **Условия бронирования.** Время заезда/выезда, размер предоплаты,
   правила отмены, точные правила проживания — в ТЗ не были указаны.
   На сайте (`#terms` и `booking-terms.html`) эти пункты помечены как
   «уточняются при подтверждении брони» — это честная формулировка для
   реальных посетителей, а не техническая заглушка для разработчика.
   Замените на конкретику, когда она будет утверждена.
6. **Домен.** В `index.html` уже проставлен `https://svoyadacha-ekb.ru/`
   (canonical, og:url, JSON-LD) — замените на свой домен после подключения.

## Форма бронирования

Форма (`#booking`) работает без бэкенда: если в `config.js` не указан
`formEndpoint`, при отправке открывается WhatsApp с готовым текстом заявки
(имя, телефон, даты, гости, комментарий). Если подключите сервис приёма
форм (Formspree, Getform, свой обработчик) — впишите его URL в
`formEndpoint`, и заявки будут уходить туда по HTTP, а WhatsApp останется
резервным вариантом при сбое.

## Персонаж «Свой» — куда его добавлять позже

Персонаж сейчас не нарисован — по брифу это следующий слой бренда, не
основа сайта. В коде уже зарезервированы места:

- **Бейдж «Свой проверил»** рядом с заголовком блока «Забота в деталях»
  (`.checked-badge` в `index.html`) — сейчас это текст с галочкой, при
  появлении иллюстрации можно добавить маленькую картинку перед текстом.
- **404-страница** — пустой контур `.mascot-slot` над заголовком
  «Такой страницы здесь нет»; готов принять иллюстрацию.
- Класс `.mascot-slot` в `styles.css` можно переиспользовать в будущем
  FAQ-блоке или в подсказках форм — по брифу это тоже допустимые места.

## Локальный просмотр

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/
```

## Публикация

Сайт статический — подходит любой хостинг: shared-хостинг по FTP,
Netlify/Vercel (папка как есть, без сборки) или GitHub Pages.
